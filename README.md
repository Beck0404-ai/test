# Дорноговь Орон Сууц - Албан хаагчдын чиг баримжаа тодорхойлох сорил

Энэхүү систем нь **Дорноговь Орон Сууц** байгууллагын албан хаагчдад зориулсан сэтгэл зүйн сорил (В.Смекал, М.Кучера / А.Бассын "Ориентация личности" сорил)-ын вэб аппликейшн юм.

## 🚀 Боломжууд:
- **Албан хаагчийн бүртгэл:** Овог нэр, албан тушаалаар баталгаажуулж сорилыг бөглөнө.
- **Албан ёсны түлхүүр:** 27 асуултын хариултыг 3 чиглэлээр (Я - Өөртөө, О - Харилцаанд, Д - Ажилд) тооцоолно.
- **Үр дүн ба Дүгнэлт:** Бөглөсөн албан хаагч өөрийн үр дүнг оноо, хувь, давамгайлах чиг баримжааны тайлбартайгаар харах болон PDF/Хэвлэж авах боломжтой.
- **Админ Панел:** Бөглөсөн бүх албан хаагчдын мэдээлэл, онооны нэгтгэлийг харах ба CSV (Excel) хэлбэрээр татан авна.
